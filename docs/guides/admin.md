# دليل الإدارة

## أول مرة
أول حساب إدارة بيتعمل يدويًا من Firebase Console (انظر `docs/ADMIN_BOOTSTRAP.md`). كل أدمن بعده بدعوة من لوحة "المدراء".

## الأقسام
نظرة عامة، الصفوف والفصول، المواد (فيه زر المواد الافتراضية)، المدرسون والإسناد (اعتماد المدرس ثم ربطه بمادة وفصل)، استيراد الطلاب، ربط أولياء الأمور، إدارة الحسابات، جدول الحصص، النسخ والأخطاء، المدراء، رسائل التواصل.

## ترتيب إعداد المدرسة
1. الصفوف والفصول ثم المواد.
2. اعتماد المدرسين وإسنادهم.
3. استيراد الطلاب: ألصق سطرًا لكل طالب (الاسم الرباعي، الهاتف) أو ارفع Excel/CSV. الطالب لما يسجل بنفس الاسم والهاتف يتربط بالفصل.
4. جدول الحصص.

## أمان
- كلمات المرور القوية، وغيّر أي كلمة مرور اتشاركت في محادثة.
- حذف فصل أو مادة أو إسناد يطلب تأكيد.
- "النسخ والأخطاء": تنزيل نسخة (يحسب من حد القراءات) وآخر الأخطاء المسجلة (بدون بيانات شخصية).
