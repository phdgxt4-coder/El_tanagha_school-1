# صفحة لتعليم مناهج الثانوية
## مدرسة التناغة الشرقية الثانوية المشتركة

منصة تعليمية متكاملة جاهزة للإنتاج.

### النشر على GitHub Pages

1. ارفع **كل محتويات هذا المجلد** إلى **جذر** الـ Repository.
2. Settings → Pages → Deploy from branch → `main` / **root**.
3. افتح الرابط.

### الهيكل

```
├── index.html
├── css/style.css
├── js/
│   ├── app.js              ← التطبيق الرئيسي
│   └── modules/            ← وحدات قابلة لإعادة الاستخدام
│       ├── config.js
│       ├── utils.js
│       ├── storage.js
│       └── chat.js
├── assets/images/ + icons/
├── manifest.webmanifest
├── sw.js
└── README.md
```

### الميزات

- تسجيل منفصل: طالب / مدرس / ولي أمر (تحقق قوي + صورة + شروط)
- لوحات تحكم مستقلة
- مواد مستقلة (11 مادة)
- دروس · فيديوهات · PDF · Word · PPT · روابط
- واجبات + تسليم + تصحيح + درجات + ملاحظات
- اختبارات وامتحانات (متعدد / صواب-خطأ / قصير) + مؤقت + تصحيح تلقائي
- **رسائل لحظية بين الطالب والمدرس** (مثل منصات المدرسين)
- حضور · درجات · إشعارات · إعلانات
- ربط ولي الأمر بكود
- Glassmorphism · داكن/فاتح · PWA · RTL
