# منصة التناغه الشرقيه الثانويه المشتركه

منصة تعليمية عربية RTL بهوية داكنة/ذهبية وبنية ES modules. الواجهة العامة مبنية بـ Vite وتُنشر عبر GitHub Pages؛ تسجيل الحسابات والصلاحيات الخاصة تعتمد Firebase Authentication وCloud Functions وFirestore Rules عند تهيئتها. غياب إعداد Firebase متوقع في النسخة الحالية: يعرض التطبيق رسالة توضيحية ولا يرسل بيانات الدخول. لا تستخدم المنصة سجلات مدرسية حقيقية حتى يؤكد مالك المدرسة المشروع والسياسات ويختبرها.

## التشغيل المحلي

```bash
pnpm install --frozen-lockfile
pnpm dev
```

يعمل Vite على المنفذ 3000. تُقرأ إعدادات Firebase Web من متغيرات `VITE_FIREBASE_*` أثناء البناء، ولا تحفظ في ملفات المصدر. لا تضف service-account JSON أو مفاتيح خاصة أو كلمات مرور إلى `.env` أو Git أو ملفات الواجهة.

## حالة التنفيذ

الواجهة العامة مكتملة في المصدر. توجد مصادقة وطلبات مدرسين ولوحات أولية وقواعد Firestore ضمن المصدر، لكن لا يوجد في هذه النسخة ما يثبت تهيئة Firebase أو نشر الوظائف والقواعد إلى مشروع حي. لوحات الأدوار وإدارة المحتوى جزئية، وواجهة المحتوى الحالية تتيح للمدرس نشر رابط HTTPS فقط. راجع [قائمة المهام والمراحل](TODO.md) و[خطة التنفيذ](plan.md) قبل تفعيل الخدمة.

## إعداد GitHub Pages

اختياريًا، مرّر إعدادات عميل Firebase إلى بناء Pages من متغيرات المستودع العامة في إعدادات GitHub Actions: `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID`، و`VITE_FIREBASE_FUNCTIONS_REGION` عند الحاجة. سير البناء يستخدمها فقط إذا كانت معرفة؛ وإن لم تكن، تبقى المنصة في حالة غير مهيأة. ينشئ `scripts/create-static-routes.mjs` ملفات دخول لكل المسارات المعرفة كي تعمل الروابط المباشرة وإعادة التحميل برمز 200. إعدادات Firebase Web عامة بطبيعتها وستُضمّن في JavaScript المنشور، فلا تحتوي أسرارًا. تقييد المفتاح لا يغني عن قواعد Firestore.

## إعداد Firebase الحي

يجب أن يؤكد المالك معرّف المشروع والمنطقة والتكلفة قبل النشر. بعد ذلك، يلزم تفعيل Email/Password وإعداد Firestore Native-mode ومراجعة `firestore.rules` و`firestore.indexes.json`؛ راجع `SETUP.md` للتفاصيل. نشر قواعد/وظائف Firebase يغيّر خدمة خارجية، ولا يتم تلقائيًا بهذا المستودع. لا تفعّل Firebase Hosting لهذا المشروع؛ الاستضافة منفصلة عبر GitHub Pages. لا يوجد مدير افتراضي؛ إنشاء سجل الإدارة خطوة يدوية موثقة بعد تحقق UID وموافقة المالك.

## التحقق

```bash
pnpm test
pnpm test:rules
pnpm build
npm test --prefix functions
```

اختبارات `pnpm test:rules` تحتاج Firestore Emulator؛ تخطيها لا يعني اجتيازها. اجتياز المحاكي أو البناء لا يثبت نشر Firebase أو اتصال تسجيل الدخول الحقيقي. اختبر الخدمة الحية بحسابات اختبار منفصلة فقط وبعد إعداد المشروع بموافقة المالك.
