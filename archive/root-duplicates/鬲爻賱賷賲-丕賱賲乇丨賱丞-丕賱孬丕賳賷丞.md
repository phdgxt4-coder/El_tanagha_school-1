# تسليم المرحلة الثانية — منصة التناغه الشرقيه الثانويه المشتركه

هذه الحزمة تضم المشروع كاملًا بآخر تحديث محفوظ في بيئة العمل، بما في ذلك ملفات المصدر والواجهة والتنسيقات والأصول والاختبارات وإعدادات Firebase وأقفال الحزم ونسخة الواجهة المبنية `dist/`.

## النشر لاحقًا

- **الواجهة:** ارفع محتويات `dist/` إلى الاستضافة التي تختارها. عند تعديل المصدر، أعد البناء باستخدام `pnpm install --frozen-lockfile` ثم `pnpm build`.
- **Firebase:** لا ترفع `functions/` كموقع ثابت. إعداد Firebase Console وربط CLI بمشروعك يسبقان نشر الوظائف والقواعد. راجع `README.md` للأوامر والخطوات. لا تستخدم Firebase Hosting لهذا المشروع.
- **إعدادات العميل:** `.env.example` مجرد قالب بقيم توضيحية، وليست إعدادات مشروع حقيقية. يلزم إدخال قيم Web الصحيحة قبل بناء الواجهة المتصلة. لا تضع service-account JSON أو مفاتيح خاصة أو كلمات مرور في ملفات الواجهة أو المستودع.
- **حساب الإدارة:** لا يوجد حساب افتراضي. يتطلب أول مدير إنشاء حساب موثوق وإضافة سجل الإدارة يدويًا بعد التحقق من UID، وفق `README.md`.

## الحالة

لم يُنشر الموقع ولا وظائف Firebase ولا قواعد Firestore، ولم تُنشأ حسابات. نجاح البناء واختبارات المحاكي المحلي لا يثبت أن المصادقة أو المزامنة تعمل على مشروع خارجي. راجع `TODO.md` و`README.md` قبل أي تفعيل.
